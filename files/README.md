# Files and Device Exports

Raw router/switch exports, inventories, logs, backups, screenshots and generated configuration can reveal credentials or the actual network even when they look like ordinary text files.

Do not mirror the private artifact directory here. Explain a reusable configuration capability in Markdown under the relevant [design](../docs/1_Design/README.md) or [setup](../docs/2_Setup/README.md) guide. Any synthetic excerpt must be independently constructed and reviewed under the [sanitization guideline](../docs/Repository_Guidelines.md#sanitization-workflow).
